Enunciado

Lucas, um organizador de eventos, precisa de um sistema para verificar rapidamente se os participantes têm idade suficiente para entrar em eventos com restrição de idade. Ele deseja uma função que informe se a pessoa é maior ou menor de idade.

Entrada: • Um inteiro positivo representando a idade da pessoa.

Saída: • Uma string contendo a mensagem "É maior de idade" ou "É menor de idade".
